## About me

- **Software Engineering** student at *Universidad Surcolombiana*, Faculty of Engineering.
- My comfort zone is the **backend**. Layered architecture, relational data modeling,
  authentication and authorization, and clean separation between domain and presentation.
- I also ship the **frontend** when the project needs it, with React and a component-driven approach.
- I learn by building complete products rather than isolated exercises — every repository here
  is a working application, not a tutorial.
